# 物流合作与自提

## 合作快递

| 区域 | 默认快递 | 可选快递 |
| --- | --- | --- |
| 华东、华南、华中 | 中通、圆通 | 不支持指定 |
| 华北、西南 | 中通、韵达 | 不支持指定 |
| 西北、东北 | 邮政、韵达 | 不支持指定 |
| 港澳台及海外 | 暂不配送 | — |

默认按收货地址自动匹配快递，暂不支持指定具体快递公司；有特殊需求请在下单前联系客服确认能否满足。

## 自提与驿站

- 下单时可选择"附近自提点"，系统展示 3 公里内的驿站与快递柜；
- 包裹到达自提点后会有取件码短信，请凭取件码在 3 天内取件；
- 超过 3 天未取件，包裹退回仓库，退款在 3 个工作日内原路退回；
- 快递柜超时会产生保管费，由收件人承担，具体以柜体提示为准。

## 保价与丢件

- 保价需在下单时勾选，费率按声明价值的 0.5% 收取，最低 1 元；
- 未保价包裹丢件，按快递公司规则赔付，通常为运费的 3 倍；
- 保价包裹丢件，按声明价值赔付，需提供商品价值凭证（订单截图或发票）；
- 丢件理赔需在签收时效届满后 7 天内提交，超时不予受理。

## 大件与特殊商品

- 大家电、家具走专线物流，配送含上门安装，需提前预约时间；
- 生鲜类仅支持次日达区域，超区会自动取消并退款；
- 液体、粉末类商品走陆运，时效比空运慢 1-2 天。

## 常见问题

Q：能自己选快递吗？
A：不支持，系统按区域自动匹配；确有需要请下单前联系客服确认。

Q：包裹放在驿站多久会被退回？
A：到达后 3 天内未取件会退回仓库，随后 3 个工作日内退款。

Q：没保价的包裹丢了怎么赔？
A：按快递公司规则赔付，通常为运费的 3 倍；保价件才按声明价值赔付。

Q：大件商品送货上门吗？
A：大家电与家具走专线，含上门安装，需要提前预约时间。
