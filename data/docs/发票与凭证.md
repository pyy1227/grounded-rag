# 发票与售后凭证

## 发票类型

| 类型 | 是否支持 | 说明 |
| --- | --- | --- |
| 电子普通发票 | 支持 | 默认开具，发送到订单预留邮箱 |
| 增值税专用发票 | 支持 | 需提供公司名称、税号、开户行及账号 |
| 纸质发票 | 不支持 | 已全面改为电子发票 |

## 开票时效

- 订单确认收货后可在订单详情页申请开票；
- 电子普票一般 **1 个工作日内** 开出；
- 增值税专票需要人工审核，**3 个工作日内** 开出；
- 开票金额为实付金额，不含优惠券抵扣部分。

## 补开与换开

- 发票丢失可在订单页重新下载电子发票，不限次数；
- 发票信息填错，可在开票后 30 天内申请换开，需先作废原发票；
- 跨年订单（超过 12 个月）原则上不再支持补开，特殊情况需财务审核。

## 售后凭证要求

| 场景 | 需要的凭证 |
| --- | --- |
| 质量问题退货 | 故障照片或视频、订单号 |
| 少件/发错货 | 开箱照片、快递面单 |
| 价保申请 | 同款商品降价截图（含时间） |
| 发票问题 | 订单号、原发票号 |

## 常见问题

Q：发票什么时候能开？
A：确认收货后申请，电子普票 1 个工作日内，增值税专票 3 个工作日内。

Q：可以开增值税专用发票吗？
A：可以，需要提供公司名称、税号、开户行和账号，审核通过后 3 个工作日内开出。

Q：发票抬头写错了怎么办？
A：开票后 30 天内可申请换开，需要先作废原发票，联系客服提交正确信息。

Q：发票金额为什么比实付少？
A：开票金额为实付金额，优惠券和平台补贴部分不计入开票金额。
