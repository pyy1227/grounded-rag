# 商品参数：便携小风扇 F10

## 基本参数

| 参数 | 数值 |
| --- | --- |
| 型号 | F10 |
| 产品尺寸 | 168 × 92 × 42 mm |
| 净重 | 215 g |
| 风力档位 | 3 档（低/中/高） |
| 最大风速 | 4.2 m/s |
| 噪音 | 低档 22 dB，高档 38 dB |
| 电池容量 | 4000 mAh |
| 充电接口 | Type-C |
| 输入功率 | 5V/2A |
| 包装清单 | 风扇 ×1、充电线 ×1、说明书 ×1、挂绳 ×1 |

## 续航与充电

| 使用档位 | 续航时间 | 充电时间 |
| --- | --- | --- |
| 低档 | 约 8 小时 | 约 2.5 小时 |
| 中档 | 约 5 小时 | 约 2.5 小时 |
| 高档 | 约 3 小时 | 约 2.5 小时 |

电池从 0 充满约 2.5 小时，支持边充边用，但边充边用时机身温度会升高 5-8 度，属于正常现象。

## 使用与保养

- 首次使用建议先充满电，长期不用时每 3 个月补电一次；
- 清洁时用干布擦拭外壳，不要用水冲洗，也不要使用酒精；
- 不要堵塞进出风口，否则会触发过热保护自动降档；
- 低温环境（0 度以下）电池容量会下降，属正常现象。

## 常见问题

Q：风扇有几档风力？
A：3 档，低档、中档、高档，最大风速 4.2 m/s。

Q：充电要多久？
A：使用 5V/2A 充电器约 2.5 小时充满，普通 5V/1A 充电器约 4 小时。

Q：能用多久？
A：低档约 8 小时，中档约 5 小时，高档约 3 小时，具体受环境温度影响。

Q：可以带上飞机吗？
A：电池容量 4000 mAh（约 14.8Wh），低于民航 100Wh 限制，可随身携带，不可托运。

Q：支持快充吗？
A：不支持快充协议，仅支持 5V/2A 标准输入。
