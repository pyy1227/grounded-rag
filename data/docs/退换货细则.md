# 退换货细则

## 退货地址与寄回方式

- 退货地址为系统生成的中心仓地址，**不要寄回商品页显示的店铺地址**；
- 支持上门取件：在退货页预约时间段，快递员上门取件，运费按退货原因判定承担方；
- 自行寄回请保留快递单号，并在退货页填写单号，否则无法跟踪进度；
- 到付件一律拒收，运费由寄件方承担的订单请在寄出前与客服确认。

## 七天无理由的边界

| 情况 | 是否支持无理由退货 |
| --- | --- |
| 未拆封、配件齐全 | 支持 |
| 已拆封但有完整吊牌与包装 | 支持，需不影响二次销售 |
| 已使用且影响二次销售 | 不支持 |
| 定制、刻字类 | 不支持 |
| 贴身用品、食品已拆封 | 不支持 |
| 赠品缺失 | 不支持，需随主商品一并寄回 |

## 换货周期

- 客服确认后生成换货单，寄回地址以客服提供为准；
- 仓库签收并检测通过后 48 小时内发出新货；
- 换货仅支持同款同规格，换其他型号需先退货再重新下单；
- 换货过程中如遇缺货，可选择等待补货或转为退货退款。

## 拒收与破损

- 包裹明显破损请当场拒收并拍照，联系客服重新发货；
- 非质量问题拒收产生的往返运费由买家承担；
- 拒收后订单会在 3 个工作日内自动退款。

## 常见问题

Q：退货可以寄回店铺地址吗？
A：不可以，必须寄回系统生成的中心仓地址，否则无法签收入库。

Q：赠品要一起寄回吗？
A：要，赠品缺失会影响退款审核，需随主商品一并寄回。

Q：换货期间商品降价了怎么办？
A：换货按同款同规格处理，不补差价；如需享受新价格，可先退货再重新下单。

Q：拒收后多久退款？
A：拒收件签收入库后 3 个工作日内原路退款。
