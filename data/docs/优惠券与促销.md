# 优惠券与促销

## 优惠券类型

| 类型 | 说明 | 使用范围 |
| --- | --- | --- |
| 平台满减券 | 满 X 元减 Y 元 | 全平台自营商品 |
| 店铺优惠券 | 指定店铺发放 | 仅限该店铺商品 |
| 品类券 | 限定品类使用 | 如数码、美妆、食品 |
| 折扣券 | 按比例打折 | 多数商品，秒杀除外 |
| 免邮券 | 抵扣一次运费 | 单笔订单仅限一张 |

## 领取与使用限制

- 每张券有领取上限，同一账号同一活动通常限领 1 张；
- 券有使用门槛（订单金额、品类、店铺），下单时系统自动筛选可用券；
- 同一订单只能使用一张平台券 + 一张店铺券，不可叠加两张同类型券；
- 优惠券不可转赠、不可提现、不可拆分使用；
- 秒杀、清仓、预售定金商品不参与任何优惠券抵扣。

## 有效期与失效

- 券面标注有效期，过期自动失效，不补发；
- 订单取消或全额退款后，未过期的券会自动退回账户，过期券不退回；
- 部分退款时券不退回，按退款比例计算实际退款金额；
- 活动券若因系统故障未能到账，可在 7 天内联系客服补发。

## 与会员折扣的关系

会员折扣与优惠券可以叠加，顺序为：平台满减 → 店铺券 → 会员折扣。
运费险、赠品不参与折扣计算。

## 常见问题

Q：为什么我的券下单时不能用？
A：常见原因是未达门槛、商品属于秒杀或清仓、或该券限定了品类与店铺。

Q：退款后优惠券会退回来吗？
A：订单取消或全额退款时，未过期的券自动退回；过期券和部分退款不退券。

Q：两张满减券可以一起用吗？
A：不可以，同一订单只能使用一张平台券和一张店铺券。

Q：券可以送给朋友吗？
A：不可以，优惠券与账号绑定，不支持转赠。
