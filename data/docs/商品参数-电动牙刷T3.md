# 商品参数：电动牙刷 T3

## 基本参数

| 参数 | 数值 |
| --- | --- |
| 型号 | T3 |
| 清洁模式 | 5 档（清洁/亮白/护龈/敏感/舌苔） |
| 震动频率 | 最高 39000 次/分钟 |
| 刷头类型 | 杜邦软毛，可替换 |
| 电池容量 | 2000 mAh |
| 续航 | 约 30 天（每天 2 次，每次 2 分钟） |
| 充电方式 | 感应式无线充电底座 |
| 充电时间 | 约 12 小时 |
| 防水等级 | IPX7（可整机水洗） |
| 包装清单 | 刷柄 ×1、刷头 ×2、充电底座 ×1、说明书 ×1 |

## 刷头与更换

- 建议每 3 个月更换一次刷头，刷毛变形或变色应提前更换；
- 刷头为通用型号 T3 专用，与其他型号不通用；
- 刷头可单独购买，两件装与四件装更划算；
- 更换刷头后无需重置，机器会自动识别。

## 使用说明

- 首次使用建议先充电 12 小时，指示灯常亮表示充满；
- 每次刷牙 2 分钟，机器每 30 秒提醒换区，2 分钟后自动停止；
- 敏感模式震动更柔和，适合初次使用或牙龈敏感人群；
- 刷牙时不要用力按压，让刷毛自然贴合牙面。

## 充电与保养

- 充电时请擦干刷柄底部，放在底座上即可，指示灯闪烁表示充电中；
- 支持整机水洗，但不要长时间浸泡在深水中；
- 长期不用建议每 3 个月充电一次，避免电池过放；
- 底座请放在干燥处，避免积水。

## 常见问题

Q：牙刷能整机水洗吗？
A：可以，IPX7 防护支持整机水洗，但不要长时间浸泡。

Q：刷头多久换一次？
A：建议 3 个月，刷毛变形或变色应提前更换。

Q：充一次电能用多久？
A：每天两次、每次两分钟的情况下约 30 天。

Q：刷牙力度要多大？
A：不要用力按压，让刷毛自然贴合牙面即可，用力过大会损伤牙龈。
