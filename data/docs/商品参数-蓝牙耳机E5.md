# 商品参数：蓝牙耳机 E5

## 基本参数

| 参数 | 数值 |
| --- | --- |
| 型号 | E5 |
| 类型 | 入耳式真无线 |
| 蓝牙版本 | 5.3 |
| 单耳重量 | 4.2 g |
| 充电盒重量 | 38 g |
| 发声单元 | 10 mm 动圈 |
| 频响范围 | 20 Hz - 20 kHz |
| 防护等级 | IPX4（防汗防溅，不防浸泡） |
| 充电接口 | Type-C |
| 包装清单 | 耳机 ×2、充电盒 ×1、耳塞（S/M/L）×3 对、充电线 ×1、说明书 ×1 |

## 续航与充电

| 使用方式 | 续航 |
| --- | --- |
| 单耳音乐播放 | 约 6 小时 |
| 配合充电盒总续航 | 约 24 小时 |
| 通话 | 约 4 小时 |
| 充电盒给耳机补电 | 约 3 次 |

充电盒从 0 充满约 1.5 小时，耳机放入盒内约 1 小时充满。支持开盖即连，不支持无线充电。

## 连接与操作

- 首次配对：开盖后长按盒内按键 3 秒进入配对模式，在手机蓝牙列表选择 E5；
- 支持双设备连接，可在两台设备间切换，同时仅一台播放；
- 触控操作：单击播放/暂停，双击切歌，长按 2 秒切换降噪/通透；
- 有效连接距离约 10 米，隔墙会衰减。

## 使用与保养

- 耳塞建议每 3 个月更换一次，可单独购买；
- 清洁请用干棉签擦拭出音孔，不要用水冲洗或浸泡；
- 长时间不用建议每 2 个月充电一次，避免电池过放；
- 高温环境（超过 45 度）会影响电池寿命。

## 常见问题

Q：耳机能戴着洗澡吗？
A：不能，IPX4 只防汗防溅，不防浸泡，进水不在保修范围。

Q：一次充电能用多久？
A：单耳约 6 小时，配合充电盒总续航约 24 小时。

Q：可以同时连两台手机吗？
A：可以双设备连接，但同一时间只有一台设备播放声音。

Q：支持无线充电吗？
A：不支持，只能通过 Type-C 有线充电。
