# RAG 评测报告（示例）

> 由 `ragagent eval --report reports/eval.md` 生成后整理。
> 数据为仓库自带 32 条演示评测集，**用于对比配置差异，不代表线上效果**。

- 数据集：`data/eval/queries.jsonl`（27 条可回答 + 5 条不可回答，题面为**口语化改写**，不照抄知识库原词）
- 运行模式：BM25 + text-embedding-v3（1024 维）+ 短语召回 → RRF 融合 → heuristic 精排
- 分词：bigram

## 核心指标

`recall@k` 只衡量检索命中（**不经过拒答过滤**）；`recall@k_effective` 叠加拒答，两者之差就是拒答策略的代价。
早期版本只在「拒答之后」算 recall@k，结果检索变差和拒答变激进混成同一个数字，看不出是哪一层的问题。

| 指标 | 数值 |
| --- | ---: |
| recall@3 | 0.963 |
| recall@3_effective | 0.5185 |
| recall@5 | 0.963 |
| recall@5_effective | 0.5185 |
| MRR | 0.8457 |
| 误拒率（over_refusal） | 0.4815 |
| 拒答准确率 | 0.6 |
| 可回答问题的平均未见词比例 | 0.6643 |
| 不可回答问题的平均未见词比例 | 0.7774 |

## 结论与取舍

**1. 检索层：真实向量明显更好，这次是能看出来的**

同一份集、同一套检索参数，只换 embedding：

| 指标 | 哈希向量（`config.offline.toml`） | text-embedding-v3（`config.toml`） |
| --- | ---: | ---: |
| recall@3 | 0.7778 | **0.9630** |
| recall@5 | 0.8148 | **0.9630** |
| MRR | 0.6142 | **0.8457** |

题面刻意用「是他们发错颜色了，寄回去的快递钱还要我掏吗」这类口语改写，字面重合很低，
哈希向量（本质是字符 bigram 的袋）扛不住，语义向量能靠 paraphrase 命中。差 15~23 个百分点。

gold 只认 `section_path`、不认正文——否则「见退货运费表格」这类只是引用别处的段落也会算命中。
本集把 3 条只写在正文里的 gold 修正成真实章节名后，严格与宽松口径数值相同，但严格口径更抗后续出题时的虚高。

外部数据集上也验过同一结论（+20pp recall@3），见 [external-eval.md](external-eval.md)。

**2. 拒答层：两套向量一样差，说明短板不在向量**

误拒率 0.4815、拒答准确率 0.6 ——换上更好的向量后**一点没变**，因为拒答信号来自 BM25 词表覆盖，
与向量质量无关。更关键的是：这次它**同时错了两头**。

根因在「未见实词比例」这个信号的分布上：

| | 旧集（照抄知识库原词） | 本集（口语化改写） |
| --- | ---: | ---: |
| 可回答问题的平均未见词比例 | 0.2463 | 0.6643 |
| 不可回答问题的平均未见词比例 | 0.8417 | 0.7774 |

旧集上两类几乎不重叠（0.25 vs 0.84），所以 0.8 这个点又准又不误伤；
本集上两类挤到一起（0.66 vs 0.78），**任何阈值都分不开**——扫遍 1.0~0.5 都找不到同时满足的取舍点。

结论：旧集上的 0.8 / 拒答准确率 0.8 是**题面复用原词**带来的虚高，不是信号真的稳。
这不是调参能修的，需要换信号（例如用检索覆盖度 + 模型判「答不答得了」，而不是数未见词）。

## 复现方式

```bash
cp .env.example .env          # 填入 DEEPSEEK_API_KEY / DASHSCOPE_API_KEY
ragagent ingest data/docs --force
ragagent eval --dataset data/eval/queries.jsonl --report reports/eval.md
```

没有 API Key 时用离线配置（哈希向量，检索指标会掉到 recall@3 0.7778 / MRR 0.6327，拒答指标不变）：

```bash
ragagent --config config.offline.toml ingest data/docs --force
ragagent --config config.offline.toml eval --report reports/eval-offline.md
```
